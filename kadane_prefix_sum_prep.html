Kadane's Algorithm

Best subarray ending at each index: either extend the previous best or start fresh.

General tips
  • Core recurrence: cur = max(x, cur + x), then best = max(best, cur). In words: if the running sum so far is negative, it only hurts, so restart at x.
  • Initialise with nums[0], not 0, when the subarray must be non-empty. Otherwise an all-negative array wrongly returns 0 instead of the largest (least negative) element.
  • Min version is the mirror image: swap max for min. Maximum absolute sum = run both and take max(max_sum, abs(min_sum)).
  • Products need two trackers. A negative flips the biggest into the smallest, so keep both a running max and a running min.
  • Circular arrays: answer = max(normal Kadane max, total - min subarray). Edge case: if every element is negative, the circular trick would select an empty array, so return the normal max.
  • One deletion: keep two states per index, "no deletion yet" and "one element already deleted", and transition between them.
  • Kadane works with negatives (unlike sliding window), runs in O(n) time and O(1) space, and is really a 1-D dynamic programming problem. Say that out loud.
  • If asked for the subarray itself, not just the sum, track a temp start index that resets whenever you restart, and copy it to (best_start, best_end) on improvement.

Maximum Subarray Sum

Given an integer array, find the contiguous subarray (at least one element) with the largest sum and return that sum.

Sample Input / Output

Input

nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]

Output

6 (subarray [4, -1, 2, 1])
# Reveal approach & solution (try it yourself first)

Approach: Kadane's algorithm. At each element, the best subarray ending here is either the element alone or the previous best plus this element. Keep a global best. O(n) time, O(1) space. The second function shows how to also return the subarray boundaries.

def max_subarray(nums):
    cur = best = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)
        best = max(best, cur)
    return best


# variant: also return the subarray indices
def max_subarray_with_indices(nums):
    cur = best = nums[0]
    start = best_start = best_end = 0
    for i in range(1, len(nums)):
        if nums[i] > cur + nums[i]:
            cur = nums[i]
            start = i
        else:
            cur += nums[i]
        if cur > best:
            best = cur
            best_start, best_end = start, i
    return best, best_start, best_end
DE interview angle: Follow-up: "do this over a stream or a partitioned dataset." Each partition keeps (total, best prefix, best suffix, best subarray), and these four values merge associatively, so it parallelises as a reduce.

Minimum Subarray Sum

Given an integer array, find the contiguous subarray with the smallest sum and return that sum.

Sample Input / Output

Input

arr = [3, -4, 2, -3, -1, 7, -5]

Output

-6 (subarray [-4, 2, -3, -1])
# Reveal approach & solution (try it yourself first)

Approach: Mirror image of Kadane: replace max with min. The best subarray ending here is the element alone or the previous minimum plus this element.

def min_subarray(arr):
    cur = best = arr[0]
    for x in arr[1:]:
        cur = min(x, cur + x)
        best = min(best, cur)
    return best
DE interview angle: Follow-up: where would you use it? Finding the worst drawdown or the worst consecutive stretch in a daily net-change series. It is also the building block for the circular and absolute-sum variants below.
K03 Medium https://leetcode.com/problems/maximum-product-subarray/

Maximum Product Subarray

Given an integer array, find the contiguous subarray with the largest product and return that product.

Sample Input / Output

Input

nums = [2, 3, -2, 4] and nums = [-2, 0, -1]

Output

6 and 0
# Reveal approach & solution (try it yourself first)

Approach: A negative number can turn the smallest product into the largest, so track both the max and the min product ending at each index. For each x, the candidates are x alone, cur_max * x, and cur_min * x. A zero naturally resets both trackers because the lone-x candidate wins.

def max_product(nums):
    cur_max = cur_min = best = nums[0]
    for x in nums[1:]:
        candidates = (x, cur_max * x, cur_min * x)
        cur_max, cur_min = max(candidates), min(candidates)
        best = max(best, cur_max)
    return best
DE interview angle: Follow-up: "why not just track the max?" Because of sign flips, shown with [-2, 3, -4]. In the data world, products show up as compounding growth rates or cumulative probabilities (often handled with logs to avoid overflow).

Maximum Subarray Sum with One Deletion

Return the maximum sum of a non-empty subarray after optionally deleting at most one element from it (the result must still be non-empty).

Sample Input / Output

Input

arr = [1, -2, 0, 3] and arr = [-1, -1, -1, -1]

Output

4 (drop -2, giving [1, 0, 3]) and -1
# Reveal approach & solution (try it yourself first)

Approach: Two states per index. no_del = best subarray ending here with nothing deleted (plain Kadane). one_del = best ending here with exactly one deletion: either we delete the current element (take the previous no_del) or we keep it and extend an earlier deletion (one_del + x). The answer is the best of both states across the array.

def maximum_sum(arr):
    no_del = best = arr[0]
    one_del = float('-inf')
    for x in arr[1:]:
        one_del = max(one_del + x, no_del)   # keep x after a deletion, or delete x itself
        no_del = max(no_del + x, x)          # plain Kadane
        best = max(best, no_del, one_del)
    return best
DE interview angle: Follow-up: "what if you could delete k elements?" That becomes a DP with a state per number of deletions used: O(n * k). Naming the generalisation shows you see the pattern as DP, not a trick.

Maximum Absolute Sum of Any Subarray

Return the maximum absolute value of the sum of any subarray. An empty subarray (sum 0) is allowed.

Sample Input / Output

Input

nums = [1, -3, 2, 3, -4] and nums = [2, -5, 1, -4, 3, -2]

Output

5 and 8
# Reveal approach & solution (try it yourself first)

Approach: The largest absolute sum is either the largest positive subarray sum or the most negative one, so run max-Kadane and min-Kadane together. Clamping at 0 (cur_max never below 0, cur_min never above 0) handles the allowed empty subarray.

def max_absolute_sum(nums):
    cur_max = cur_min = best = 0
    for x in nums:
        cur_max = max(0, cur_max + x)
        cur_min = min(0, cur_min + x)
        best = max(best, cur_max, -cur_min)
    return best
DE interview angle: Follow-up: equivalent to max(prefix) - min(prefix) over the prefix sums, which is a great one-line alternative to mention. In analytics terms, the largest swing in a running balance.

Maximum Sum in Circular Array

Given a circular integer array, return the maximum sum of a non-empty subarray, where the subarray may wrap around the end.

Sample Input / Output

Input

nums = [5, -3, 5] and nums = [-3, -2, -3]

Output

10 (wraps: 5 + 5) and -2
# Reveal approach & solution (try it yourself first)

Approach: Two cases. (1) The best subarray does not wrap: plain Kadane max. (2) It wraps: then the elements left out form a contiguous minimum subarray, so the answer is total - min_subarray. Take the larger. Edge case: if the plain max is negative, all elements are negative and case 2 would pick an empty set, so return the plain max.

def max_subarray_circular(nums):
    total = 0
    cur_max = cur_min = 0
    best_max = float('-inf')
    best_min = float('inf')
    for x in nums:
        total += x
        cur_max = max(x, cur_max + x)
        best_max = max(best_max, cur_max)
        cur_min = min(x, cur_min + x)
        best_min = min(best_min, cur_min)
    if best_max < 0:
        return best_max
    return max(best_max, total - best_min)
DE interview angle: Follow-up: "why does total - min work?" The wrap-around segment is the complement of a contiguous middle block, so maximising the wrap means minimising what you leave out. Stating that complement argument clearly is the senior-level signal here.

Best Time to Buy and Sell Stock

Given daily prices, return the maximum profit from one buy followed by one sell, or 0 if no profit is possible.

Sample Input / Output

Input

prices = [7, 1, 5, 3, 6, 4]

Output

5 (buy at 1, sell at 6)
# Reveal approach & solution (try it yourself first)

Approach: Kadane in disguise: it is the maximum subarray sum of the day-to-day price differences. The usual implementation tracks the lowest price so far and the best profit from selling today.

def max_profit(prices):
    min_price = float('inf')
    best = 0
    for p in prices:
        min_price = min(min_price, p)
        best = max(best, p - min_price)
    return best
DE interview angle: Bonus: spotting that this equals Kadane on the diff array is a nice pattern-recognition moment. Connect it to a window function: max(price - min(price) over (order by day rows unbounded preceding)).

Prefix Sum + Hash Map

Solutions below are copied from your Databricks notebook as-is, including its own test values at the top of each snippet. Change nums/k to the sample input to dry-run.

General tips
  • Core idea: a subarray sum is prefix[j] - prefix[i]. So "find a subarray with sum k" becomes "have I seen a prefix equal to running - k before?".
  • Counting problems (how many subarrays): the dict stores counts of each prefix value, seeded with {0: 1} so subarrays starting at index 0 are counted.
  • Longest-length problems: the dict stores the first index where each prefix appeared, seeded with {0: -1}. Never overwrite an existing key, since the earliest index gives the longest subarray.
  • Divisibility problems: store prefix % k instead of the raw sum. Two equal remainders mean the sum between them is a multiple of k. Python's % returns a non-negative result for negatives, so no extra fix-up is needed (in Java/C++ add k then mod again).
  • Binary 0/1 equal-count problems: map 0 to -1 so "equal zeros and ones" becomes "prefix returns to a previous value".
  • Minimum length of 2 (Continuous Subarray Sum): store the first index of each remainder and check that the gap is at least 2.
  • Works with negatives, unlike sliding window. Complexity is O(n) time, O(n) space (O(k) for remainder problems).

Subarray Sum Equals K

Given an integer array nums and an integer k, return the total number of subarrays whose sum equals k.

Sample Input / Output

Input

nums = [1, 2, 3], k = 3

Output

2 ([1, 2] and [3])
# Reveal approach & solution (try it yourself first)

Approach: Prefix sum with a dict of counts, seeded with {0: 1} (the empty prefix). If prefix_sum - k was seen before, each earlier occurrence marks a valid subarray ending at i. Then record the current prefix_sum.

# Subarray Sum Equals K
# Given an array of integers nums and an integer k, return the total number of subarrays whose sum equals to k.
# nums = [1,2,3]
# k = 3
nums = [1]
k = 0
mp = {0: 1}  # prefix sum 0 seen once (empty prefix)

prefix_sum = 0
ans = 0
for i in range(len(nums)):
    prefix_sum += nums[i]

    if prefix_sum - k in mp:
        ans += mp[prefix_sum - k]
    if prefix_sum in mp:
        mp[prefix_sum] += 1
    else:
        mp[prefix_sum] = 1

print(ans)
DE interview angle: Follow-up: "why not sliding window?" Negatives break the monotonic grow/shrink logic, while prefix sums do not care about sign. In Spark/SQL terms, this is a self-join on running totals (prefix = prefix_prev + k).

Subarray Sums Divisible by K

Given an integer array nums and an integer k, return the number of non-empty subarrays whose sum is divisible by k.

Sample Input / Output

Input

nums = [4, 5, 0, -2, -3, 1], k = 5

Output

7
# Reveal approach & solution (try it yourself first)

Approach: Store counts of prefix_sum % k. Two equal remainders mean the subarray between them sums to a multiple of k. Seed with {0: 1}. Python's % is non-negative for negative numbers, so negatives need no special handling.

# Given an integer array nums and an integer k, return the number of non-empty subarrays that have a sum divisible by k.

# A subarray is a contiguous part of an array.

# Example 1:

# Input: nums = [4,5,0,-2,-3,1], k = 5
# Output: 7
# Explanation: There are 7 subarrays with a sum divisible by k = 5:
# [4, 5, 0, -2, -3, 1], [5], [5, 0], [5, 0, -2, -3], [0], [0, -2, -3], [-2, -3]

def subarraysDivByK(self, nums: List[int], k: int) -> int:
    mp = {0: 1}
    prefix_sum = 0
    ans = 0

    for num in nums:
        prefix_sum += num

        if (prefix_sum % k) in mp:
            ans += mp[prefix_sum % k]

        if (prefix_sum % k) not in mp:
            mp[(prefix_sum % k)] = 1
        else:
            mp[(prefix_sum % k)]+=1


    return(ans)
DE interview angle: Follow-up: the key is the pigeonhole insight: there are only k possible remainders, so space is O(k), not O(n). That bounded-state view is useful when the data is too large to hold every distinct prefix.

Binary Subarrays With Sum

Given a binary array nums and an integer goal, return the number of non-empty subarrays whose sum equals goal.

Sample Input / Output

Input

nums = [1, 0, 1, 0, 1], goal = 2

Output

4
# Reveal approach & solution (try it yourself first)

Approach: Exactly the Subarray Sum Equals K pattern with goal in place of k. Count how many times prefix_sum - goal has appeared. Handles the all-zeros case (goal = 0) correctly because of the {0: 1} seed.

# Given a binary array nums and an integer goal, return the number of non-empty subarrays with a sum goal.

# A subarray is a contiguous part of the array.
nums = [0,0,0,0,0]
goal = 0

mp = {0: 1}
prefix_sum = 0
ans = 0
for i in range(len(nums)):
    prefix_sum += nums[i]

    if prefix_sum - goal in mp:
        ans += mp[prefix_sum - goal]

    if prefix_sum in mp:
        mp[prefix_sum] += 1
    else:
        mp[prefix_sum] = 1

print(ans)
DE interview angle: Follow-up: because values are only 0/1, a sliding-window "at most goal minus at most goal-1" solution also works in O(1) space. Mention it as the alternative and say why prefix sums generalise better (they survive negatives).

Contiguous Array

Given a binary array nums, return the maximum length of a contiguous subarray with an equal number of 0s and 1s.

Sample Input / Output

Input

nums = [0, 1, 0]

Output

2 ([0, 1] or [1, 0])
# Reveal approach & solution (try it yourself first)

Approach: Treat 0 as -1 and 1 as +1. Equal counts means the running sum returns to a value seen before. Solution 1 stores the first index of each prefix sum with a {0: -1} seed and never overwrites it, since the earliest index gives the longest subarray. Solution 2 skips the seed and instead handles the case where the prefix sum itself equals the target (0) by setting ans = i + 1, which covers subarrays starting at index 0.

# ---------- Solution 1: seed the map with {0: -1} ----------
# Given a binary array nums, return the maximum length of a contiguous subarray with an equal number of 0 and 1.
nums = [0, 1]

mp = {0: -1}  # prefix sum 0 first seen at index -1 (before array starts)
prefix_sum = 0
ans = 0

for i in range(len(nums)):
    # Treat 0 as -1, 1 as +1 so equal count means prefix_sum returns to a previous value
    if nums[i] == 0:
        prefix_sum -= 1
    else:
        prefix_sum += 1

    if prefix_sum in mp:
        ans = max(ans, i - mp[prefix_sum])
    else:
        mp[prefix_sum] = i

print(ans)


# ---------- Solution 2: no seed, handle prefix == target separately ----------
def findMaxLength(self, nums: List[int]) -> int:
    mp = {}
    ans = 0
    prefix_sum = 0
    target = 0


    for i in range(len(nums)):
        if nums[i]==0:
            prefix_sum -= 1
        else:
            prefix_sum += nums[i]

        if prefix_sum == target:
            ans = i+1
        if prefix_sum-target in mp:
            ans = max(ans,(i-mp[prefix_sum-target]))
        if prefix_sum not in mp:
            mp[prefix_sum] = i

    return(ans)
DE interview angle: Follow-up: the "map 0 to -1" transformation is the trick to name out loud. The same idea solves "equal number of two categories" problems, e.g. balanced success/failure windows in an event log. Be ready to explain why both solutions are equivalent: the {0: -1} seed in Solution 1 does the same job as the explicit prefix == 0 check in Solution 2.

Maximum Size Subarray Sum Equals K

Given an integer array nums and an integer k, return the maximum length of a contiguous subarray whose sum equals k. Return 0 if none exists.

Sample Input / Output

Input

nums = [1, -1, 5, -2, 3], k = 3

Output

4 (subarray [1, -1, 5, -2])
# Reveal approach & solution (try it yourself first)

Approach: Same prefix-sum idea but now we want the longest match, not the count. Store only the first index of each prefix sum (seed {0: -1}). If prefix_sum - k exists, the length is i - mp[prefix_sum - k].

# Given an array of integers nums and an integer k, return the maximum length of a contiguous subarray whose sum equals k.
# If no such subarray exists, return 0.

nums = [1, -1, 5, -2, 3]
k = 3

mp = {0: -1}  # prefix sum 0 first seen at index -1 (before array starts)
prefix_sum = 0
ans = 0

for i in range(len(nums)):
    prefix_sum += nums[i]

    # If (prefix_sum - k) was seen before, subarray from that index+1 to i sums to k
    if prefix_sum - k in mp:
        ans = max(ans, i - mp[prefix_sum - k])

    # Store first occurrence only (earliest index gives max length)
    if prefix_sum not in mp:
        mp[prefix_sum] = i

print(ans)
DE interview angle: Follow-up: contrast it with the counting version out loud. Counting stores frequencies and is seeded with {0: 1}; max-length stores first indices and is seeded with {0: -1}. Interviewers often probe exactly this distinction.

Continuous Subarray Sum

Return true if nums has a subarray of length at least 2 whose sum is a multiple of k, otherwise false.

Sample Input / Output

Input

nums = [23, 2, 4, 6, 7], k = 6

Output

true ([2, 4] sums to 6)
# Reveal approach & solution (try it yourself first)

Approach: Store the first index of each prefix_sum % k. If the same remainder appears again at least 2 indices later, the elements in between sum to a multiple of k. A remainder of 0 at i >= 1 means the whole prefix qualifies on its own.

# Given an integer array nums and an integer k, return true if nums has a good subarray or false otherwise.

# A good subarray is a subarray where:

# its length is at least two, and
# the sum of the elements of the subarray is a multiple of k.
# Note that:

# A subarray is a contiguous part of the array.
# An integer x is a multiple of k if there exists an integer n such that x = n * k. 0 is always a multiple of k.


# Example 1:

# Input: nums = [23,2,4,6,7], k = 6
# Output: true
# Explanation: [2, 4] is a continuous subarray of size 2 whose elements sum up to 6.

def checkSubarraySum(self, nums: List[int], k: int) -> bool:
    ans = False
    prefix_sum = 0
    mp = {}
    for i in range(len(nums)):
        prefix_sum += nums[i]
        rem = prefix_sum % k

        if rem == 0 and i >= 1:
            return True

        if rem in mp:
            if i - mp[rem] >= 2:
                return  True
        else:
            mp[rem] = i

    return(ans)
DE interview angle: Follow-up: why store only the first index? Because the first occurrence gives the widest gap, so one comparison decides it. Edge case to mention: LeetCode guarantees k >= 1 here; with k = 0 the modulo would fail and you would need a separate branch.
$ tip — both patterns are O(n) single passes, which is exactly why they map well to Spark: Kadane-style and prefix-sum logic become window functions (sum over rows unbounded preceding) or a distributed scan with per-partition partial results that are merged.
