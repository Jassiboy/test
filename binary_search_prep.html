General tips
  • Precondition: binary search works whenever there is a monotonic yes/no condition (false...false, true...true), not only on "sorted arrays". Always ask: what is my condition, and is it monotonic?
  • Template A (exact match): while low <= high, mid, return on match, otherwise low = mid + 1 or high = mid - 1. Used in rotated-array search.
  • Template B (converge to a boundary): while low < high, and high = mid (keep the candidate) or low = mid + 1. When the loop ends, low == high is the answer. Used for ceiling, mountain peak, and minimum in a rotated array.
  • Avoid infinite loops: with left-mid ((low + high) // 2) never write low = mid; always low = mid + 1. If you really need low = mid, use right-mid (low + high + 1) // 2.
  • Find first / last occurrence: on a match, record the index and keep searching left (first) or right (last) instead of returning.
  • Ceiling = smallest element >= x (lower bound); floor = largest element <= x. Handle the edge cases first: empty array, x above the max, x at or below the first element.
  • Rotated array: at least one half around mid is always sorted. Decide which one, then check whether the target lies inside that sorted range. Duplicates can degrade this to O(n).
  • Binary search on the answer: when the question is "what is the minimum X such that a condition holds", search over the range of possible X and write a feasible(X) check. Complexity is O(n log range).
  • In Python, bisect_left / bisect_right give lower/upper bound for free, but interviewers still expect you to write the loop by hand.
