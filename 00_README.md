I gave an embedding model three sentences:

**This is good.**
**This is not good.**
**This is not good?**

Tiny changes. Different meanings.

But what happens to their vectors?

Does adding **“not”** move the sentence far away in vector space?
Does **“.” → “?”** change the embedding?

And how can a bunch of numbers capture meaning?

I explored it with a simple example.

**The answer is more interesting than it looks.**
